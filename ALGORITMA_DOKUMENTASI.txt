# DOKUMENTASI ALGORITMA PENJADWALAN
# Iterated Local Search (ILS) dengan Hill Climbing

## OVERVIEW
Sistem penjadwalan otomatis menggunakan algoritma Iterated Local Search (ILS)
dengan Hill Climbing untuk mencari solusi optimal dengan penalty = 0 (tidak ada konflik).

## ALGORITMA YANG DIGUNAKAN

### 1. Iterated Local Search (ILS)
- Membuat multiple initial solutions dengan variasi
- Setiap iterasi menghasilkan solusi baru yang berbeda
- Menyimpan solusi terbaik yang ditemukan
- Berhenti jika penalty = 0 atau mencapai iterasi maksimal

### 2. Hill Climbing
- Memperbaiki solusi dengan mencari neighbor yang lebih baik
- Neighborhood operations:
  * Swap: Menukar 2 slot jadwal
  * Move: Memindahkan 1 slot ke posisi lain
  * Shift: Memindahkan seluruh session ke waktu berbeda
- Selalu memilih neighbor dengan penalty terendah

## PENALTY FUNCTION (FITNESS)

Total Penalty = Weighted Sum of:

1. **Unscheduled Penalty (Bobot: 1000)** ⭐ PALING PENTING
   - Setiap jam yang belum terjadwal = +1
   - Memastikan SEMUA assignment terjadwal 100%

2. **Teacher Conflict Penalty (Bobot: 100)**
   - Guru mengajar di 2 kelas bersamaan = +1 per konflik
   - Memastikan TIDAK ADA TABRAKAN guru

3. **PJOK Constraint Penalty (Bobot: 50)**
   - Sesi 2 jam PJOK dimulai setelah jam ke-4 = +1
   - Memastikan PJOK maksimal jam ke-5

4. **MGMP Constraint Penalty (Bobot: 50)**
   - Guru MGMP mengajar Rabu jam 6+ = +1
   - Memastikan guru SKI, B.Arab, dll bebas Rabu sore

5. **Session Continuity Penalty (Bobot: 30)**
   - Sesi tidak berurutan = +1
   - Memastikan sesi 2-3 jam berurutan

6. **Empty Slot Penalty (Bobot: 20)**
   - Setiap jam kosong = +1
   - Meminimalkan jam kosong di jadwal

7. **Teacher Load Penalty (Bobot: 5)**
   - Guru mengajar > 7 jam per hari = +1 per jam ekstra
   - Distribusi beban mengajar merata

## TARGET: PENALTY = 0
✓ Semua assignment terjadwal
✓ Tidak ada tabrakan guru
✓ Semua constraint terpenuhi
✓ Tidak ada jam kosong (atau minimal)

## FITUR TAMBAHAN

### Pattern Mata Pelajaran
- Matematika & IPA: 3-2 (sesi 3 jam + sesi 2 jam)
- Bahasa Indonesia: 2-2-2 (3 sesi @ 2 jam)
- Bahasa Inggris & IPS: 2-2 (2 sesi @ 2 jam)
- Mapel 3 jam: 2-1
- Mapel 4 jam: 2-2
- Mapel lainnya: disesuaikan otomatis

### Distribusi Jam per Hari
- Senin, Selasa, Rabu: 10 jam
- Kamis: 9 jam
- Jumat: 8 jam

### Prioritas Penjadwalan
1. PJOK (harus di jam awal)
2. Sesi panjang (3 jam) duluan
3. Random untuk variasi

## HASIL OUTPUT

### Format Jadwal:
- Menggunakan **ID GURU** (bukan nama lengkap)
- Contoh: "1a" = Guru ID 1, mengajar mapel ke-1
- Contoh: "1b" = Guru ID 1, mengajar mapel ke-2

### GUI Menampilkan:
- Tab per kelas (7A, 7B, dst)
- Jadwal lengkap Senin-Jumat
- Tab "Ringkasan Guru" untuk monitoring
- Status terjadwal (hijau = ✓, merah = belum selesai)

## PARAMETER ALGORITMA

- Max Iterations (ILS): 50
- Max Hill Climbing per ILS: 500
- Neighbors per iteration: 30
- Stop if no improvement: 15 iterasi
- Target: Penalty = 0

## CARA KERJA

1. User pilih file Excel
2. Klik "Generate Jadwal"
3. Algoritma berjalan:
   - Generate initial solution (greedy)
   - Hill climbing untuk improve
   - Restart jika stuck (ILS)
   - Ulangi sampai penalty = 0 atau max iterasi
4. Tampilkan hasil di window baru
